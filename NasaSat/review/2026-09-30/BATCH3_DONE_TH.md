## หน้าตาที่ Opus ออกแบบใหม่ (แนวคิด: แผงเครื่องมือวัดในแล็บ ไม่ใช่ dashboard เว็บทั่วไป)
- **สี**: พื้นเทาอุ่น (กระดาษ / graphite ตอนมืด), เส้นบาง 1px, ปุ่มหลักสีหมึก (ดำ / ขาวตอนมืด) แทนปุ่มฟ้าแบบ GitHub; สีใช้บอกความหมายเท่านั้น: เขียว = เข้าเป้า, เหลืองอำพัน = ต้องดู, แดง = พัง/STOP, ฟ้าอมเขียว = ตัวจำลอง, ฟ้า/ส้ม = LDR ซ้าย/ขวา (ผ่านตัวตรวจตาบอดสีของ skill dataviz ทั้งสว่างและมืด)
- **ฟอนต์**: IBM Plex Sans Thai (ไทย + อังกฤษ ตัวเลขกว้างเท่ากันทุกตัว ค่าสดจึงไม่ส่าย) เอามาจาก `Desktop/samsung inno/fonts` ตัดเหลือเฉพาะไทย+อังกฤษ 3 น้ำหนัก (400/500/600) เป็น WOFF ใน `tool/src/fonts/` แล้ว `build.js` ฝังเป็น base64 ลงไฟล์ → ทุกเครื่องเห็นเหมือนกันแม้ออฟไลน์ ไม่ต้องติดตั้งฟอนต์ (SIL OFL 1.1, มี `OFL.txt`); ตัด ✓ ออกจาก subset เพราะ glyph ของ Plex ดูเหมือน √
- **แถบบน**: เป็นช่องเครื่องวัดเรียงกัน (หัวข้อเล็ก + ค่า) แทนป้ายมน: ช่องทาง (ตัวจำลอง = ป้ายฟ้าอมเขียว + เส้นใต้แถบ), ภารกิจ 1, งานที่บอร์ดกำลังทำ, θ ตัวใหญ่, error ภารกิจ 1, มุมตัวขับ (≥1440px), แสงที่เซนเซอร์, ระบบ (≥1600px); สถานะใช้สี่เหลี่ยมเล็ก + คำ (ไม่ใช่สีอย่างเดียว); หน่วย ° ซ่อนเมื่อไม่มีค่า; เลขติดลบใช้เครื่องหมายลบจริง (−)
- **เมนูซ้าย**: "ลำดับวันแข่ง" 1–5 + สี่เหลี่ยมสถานะท้ายชื่อ (เขียว = ทำแล้ว, ครึ่ง = ทำบางขั้น) และ "เครื่องมือ"
- **ปุ่ม**: ปุ่มที่ส่งคำสั่งมีรหัสคำสั่งต่อท้ายหลังเส้นคั่น (เช่น `วัดแสงรอบข้าง │ AMB 600`); ปุ่มที่ชื่อซ้ำคำสั่งเปลี่ยนเป็นคำไทย (LOCK → ล็อกแสง, INIT → เริ่มกล้อง, SAVE → บันทึกถาวร ฯลฯ), ปุ่ม MOVE ±x เหลือแค่ตัวเลข (คำสั่งอยู่ใน tooltip)
- **ขั้นคาลิเบรต**: แถบเดียวแบ่ง 8 ช่อง (01–08) ขั้นที่เปิดอยู่มีขอบหมึกด้านบน ขั้นที่เสร็จมีสี่เหลี่ยมเขียว
- **กล่องตัดสิน**: พื้นกลาง ขอบซ้ายและหัวข้อบอกผล แถวเกณฑ์คั่นด้วยเส้นบาง; เฉพาะ "ไม่ผ่าน" เท่านั้นที่พื้นเป็นสีแดงอ่อน
- **หน้าปัดมุม**: ขีดทุก 10° ตัวเลขทุก 30° (ใช้ −); กราฟ: เส้นกริดทึบบาง เส้นศูนย์เข้มขึ้นหนึ่งขั้น, แถบเกณฑ์ผ่านเห็นชัดขึ้น, ตัวเลขแกนใช้ฟอนต์เดียวกัน
- ช่องในฟอร์มคาลิเบรตขั้น 1/5 เปลี่ยนเป็นชื่ออยู่บน ช่องกรอกอยู่ล่าง (ไม่ห่างกันจนอ่านยาก)
- ทางลัดสำหรับซ้อม/ถ่ายภาพหน้าจอ: `NasaSatLab.html#sim&tab=m1&theme=dark&cmd=M1 START` (`step=5` เปิดขั้นคาลิเบรต, `wait 2000` = รอ)
