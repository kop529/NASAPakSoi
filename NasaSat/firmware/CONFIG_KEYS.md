# ค่าตั้งทั้งหมดของ NasaSat (สร้างอัตโนมัติ อย่าแก้มือ)

สร้างจาก `tool/src/js/06_cfgdefs.js` ด้วย `node firmware/tools/gen_cfg.js` (ไฟล์เดียวกับที่ใช้สร้าง `cfg_table.h`)
ตั้งค่าด้วย `SET key value` เก็บถาวรด้วย `SAVE` ค่า i = จำนวนเต็ม, f = ทศนิยม


## เซนเซอร์ (sen)

| key | ชนิด | ค่าเริ่มต้น | ช่วง | หน่วย | ความหมาย |
|---|---|---|---|---|---|
| `sen.pin0` | i | 1 | 0 … 48 |  | ขา ADC ของ LDR ซ้าย (ช่อง 0) ใช้ GPIO1–10 (ADC1) จะดีที่สุด |
| `sen.pin1` | i | 2 | 0 … 48 |  | ขา ADC ของ LDR ขวา (ช่อง 1) ใช้ GPIO1–10 (ADC1) จะดีที่สุด |
| `sen.topo` | i | 0 | 0 … 1 |  | 0 = LDR ต่อฝั่ง 3.3V (สว่าง = mV สูง), 1 = LDR ต่อฝั่ง GND |
| `sen.vcc` | f | 3300 | 2500 … 3600 | mV | แรงดันเลี้ยงวงจรแบ่งแรงดัน |
| `sen.win` | i | 20 | 5 … 200 | ms | หน้าต่างเฉลี่ย (ใช้เท่าของ 10 ms เพื่อตัดไฟกระพริบ 100 Hz) |
| `sen.ema` | f | 1 | 0.02 … 1 |  | น้ำหนักค่าใหม่ของตัวกรอง EMA (1 = ไม่กรอง) |

## คำนวณมุมแสง (est)

| key | ชนิด | ค่าเริ่มต้น | ช่วง | หน่วย | ความหมาย |
|---|---|---|---|---|---|
| `est.alpha` | f | 30 | -85 … 85 | deg | มุมเอียงของ LDR แต่ละตัวจากแกนกลาง (ติดลบ = ช่องซ้าย/ขวาสลับกับทิศมอเตอร์) |
| `est.gamma` | f | 0.6 | 0.2 … 1.5 |  | ค่า γ ของ LDR ซ้าย (GL5528 ≈ 0.6) ถ้า est.gammaR = 0 ใช้กับทั้งสองตัว |
| `est.gammaR` | f | 0 | 0 … 1.5 |  | ค่า γ ของ LDR ขวา (0 = เท่ากับ est.gamma) การ Fit หลังวัดแสงรอบข้างจะหาให้เอง (ช่วยเพิ่มความแม่นเล็กน้อย) |
| `est.qL` | f | 1 | 0.3 … 6 |  | รูปทรงการตอบสนองช่องซ้าย (กล่องครอบ + γ จริงของ LDR, 1 = โคไซน์ปกติ) |
| `est.qR` | f | 1 | 0.3 … 6 |  | รูปทรงการตอบสนองช่องขวา (กล่องครอบ + γ จริงของ LDR, 1 = โคไซน์ปกติ) |
| `est.g` | f | 1 | 0.01 … 100 |  | gain ช่องขวาเทียบช่องซ้าย (จาก BAL หรือการ Fit) |
| `est.aL` | f | 0 | 0 … 1000000 |  | แสงรอบข้างช่องซ้าย (จาก AMB หรือการ Fit) |
| `est.aR` | f | 0 | 0 … 1000000 |  | แสงรอบข้างช่องขวา (จาก AMB หรือการ Fit) |
| `est.th0` | f | 0 | -45 … 45 | deg | ชดเชยมุมศูนย์ของแกนดาวเทียมเทียบแกนเซนเซอร์ |
| `est.lut` | i | 1 | 0 … 1 |  | 1 = ใช้ตาราง LUT แก้ค่ามุม |
| `est.minS` | f | 0.05 | 0 … 1000000 |  | ความสว่างรวมขั้นต่ำที่ถือว่าเห็นแสง |
| `est.dmax` | f | 0.95 | 0.2 … 1 |  | |D| เกินค่านี้ = อยู่นอกช่วงวัดแม่น (ขอบ) ตัวควบคุมจะหมุนแบบหยาบแทน |

## ตัวขับ (act)

| key | ชนิด | ค่าเริ่มต้น | ช่วง | หน่วย | ความหมาย |
|---|---|---|---|---|---|
| `act.type` | i | 1 | 0 … 2 |  | 0 = ไม่มีตัวขับ, 1 = stepper ULN2003, 2 = servo |
| `act.in1` | i | 38 | 0 … 48 |  | ขา IN1 ของ ULN2003 |
| `act.in2` | i | 39 | 0 … 48 |  | ขา IN2 ของ ULN2003 |
| `act.in3` | i | 40 | 0 … 48 |  | ขา IN3 ของ ULN2003 |
| `act.in4` | i | 41 | 0 … 48 |  | ขา IN4 ของ ULN2003 |
| `act.seq` | i | 2 | 0 … 2 |  | 0 = wave, 1 = full-step, 2 = half-step |
| `act.spr` | f | 4096 | 100 … 20000 | step | จำนวน step ต่อรอบ (28BYJ-48 แบบ half-step ประมาณ 4076–4096) |
| `act.vmax` | f | 40 | 1 … 150 | deg/s | ความเร็วสูงสุด (เร็วเกินไปมอเตอร์จะหลุด step) |
| `act.acc` | f | 150 | 5 … 3000 | deg/s² | ความเร่ง |
| `act.bl` | f | 0 | 0 … 10 | deg | ชดเชย backlash ตอนกลับทิศ (วัดด้วยคำสั่ง BACKLASH) |
| `act.hold` | i | 0 | 0 … 1 |  | 1 = จ่ายไฟขดลวดค้างตอนหยุด, 0 = ปล่อย (ร้อนน้อยและ noise น้อย) |
| `act.dir` | i | 1 | -1 … 1 |  | ทิศบวกของมอเตอร์ (1 หรือ -1) |
| `act.min` | f | -170 | -720 … 0 | deg | มุมต่ำสุดที่ยอมให้หมุน (กันสายพัน) |
| `act.max` | f | 170 | 0 … 720 | deg | มุมสูงสุดที่ยอมให้หมุน (กันสายพัน) |
| `act.spin` | i | 42 | 0 … 48 |  | ขาสัญญาณ servo |
| `act.smin` | f | 500 | 300 … 1500 | µs | ความกว้างพัลส์ servo ที่มุมต่ำสุด |
| `act.smax` | f | 2500 | 1500 … 2800 | µs | ความกว้างพัลส์ servo ที่มุมสูงสุด |
| `act.srng` | f | 180 | 30 … 360 | deg | ช่วงมุมทั้งหมดของ servo |

## การควบคุม (ctl)

| key | ชนิด | ค่าเริ่มต้น | ช่วง | หน่วย | ความหมาย |
|---|---|---|---|---|---|
| `ctl.k` | f | 0.85 | 0.1 … 1.5 |  | สัดส่วนการแก้มุมต่อรอบ (1 = แก้เต็มที่วัดได้) |
| `ctl.db` | f | 0.3 | 0.02 … 5 | deg | deadband: error ไม่เกินค่านี้ถือว่าตรงแล้ว |
| `ctl.hys` | f | 1 | 0.05 … 10 | deg | ตอน HOLD ถ้า error เกินค่านี้จะกลับไปปรับใหม่ (hysteresis) |
| `ctl.trim` | i | 3 | 0 … 20 |  | ตอน HOLD ถ้า error เกิน deadband ติดกันครบกี่ครั้งจึงขยับแก้เล็กน้อยโดยยังล็อกอยู่ (แก้ error ค้างที่ต่ำกว่า ctl.hys, 0 = ไม่แก้) |
| `ctl.adapt` | i | 1 | 0 … 1 |  | 1 = ถ้าค่าที่วัดแกว่ง (noise สูง) ภารกิจ 1 เฉลี่ยนานขึ้นเอง (สูงสุด 400 ms) และขยาย deadband เท่าที่จำเป็น จึงล็อกได้แม้บอร์ด noise สูง (บอร์ดเงียบไม่เปลี่ยนอะไร) |
| `ctl.wait` | i | 150 | 0 … 3000 | ms | รอให้นิ่งหลังขยับก่อนวัด (LDR ต้องใช้เวลาตามทัน) |
| `ctl.meas` | i | 60 | 10 … 2000 | ms | เวลาเฉลี่ยค่าต่อการวัด 1 ครั้ง |
| `ctl.nlock` | i | 3 | 1 … 20 |  | ต้องอยู่ใน deadband ติดกันกี่ครั้งจึงล็อก |
| `ctl.appr` | i | 1 | -1 … 1 |  | เข้าเป้าจากทิศเดียวกันเสมอ (1 หรือ -1, 0 = ปิด) ลดผลของ backlash |
| `ctl.maxstep` | f | 60 | 1 … 180 | deg | ขยับได้มากสุดต่อ 1 รอบการแก้ |

## ภารกิจ 1 (m1)

| key | ชนิด | ค่าเริ่มต้น | ช่วง | หน่วย | ความหมาย |
|---|---|---|---|---|---|
| `m1.tgt` | f | 0 | -80 … 80 | deg | มุมแสงที่ต้องการเทียบตัวดาวเทียม (0 = หันตรงเข้าหาแสง) |
| `m1.tol` | f | 1 | 0.05 … 20 | deg | เกณฑ์ผ่านของภารกิจ (ใช้ตัดสินผ่าน/ไม่ผ่าน) |
| `m1.smin` | f | -160 | -720 … 0 | deg | ช่วงค้นหาแสง: มุมเริ่ม |
| `m1.smax` | f | 160 | 0 … 720 | deg | ช่วงค้นหาแสง: มุมสุดท้าย |
| `m1.sstep` | f | 20 | 1 … 90 | deg | ระยะก้าวตอนค้นหาแสง |
| `m1.auto` | i | 0 | 0 … 600 | s | เริ่มภารกิจ 1 เองหลังเปิดเครื่องกี่วินาที (0 = ปิด) สำหรับตอนไม่ต่อคอม/ใช้แบต ต้อง SAVE ก่อน กด STOP ระหว่างรอเพื่อยกเลิก |

## กล้อง (cam)

| key | ชนิด | ค่าเริ่มต้น | ช่วง | หน่วย | ความหมาย |
|---|---|---|---|---|---|
| `cam.model` | i | 0 | 0 … 4 |  | รุ่นกล้อง: 0 = ไม่มี, 1 = ESP32-S3-EYE/Freenove, 2 = XIAO ESP32S3 Sense, 3 = กำหนดเองใน board_config.h, 4 = ESP32-CAM (AI-Thinker) (เปลี่ยนแล้วต้อง M2 INIT หรือ REBOOT) |
| `cam.hmirror` | i | 0 | 0 … 1 |  | 1 = กลับภาพซ้าย-ขวา (มีผลกับภาพถัดไป) เว็บคิดทิศภาพตามค่านี้ให้เอง |
| `cam.vflip` | i | 0 | 0 … 1 |  | 1 = กลับภาพบน-ล่าง (ภาพกลับหัว มีผลกับภาพถัดไป) |
| `cam.dir` | i | 0 | -1 … 1 |  | ทิศภาพเทียบมุมตัวขับเมื่อ cam.hmirror = 0 (ปุ่ม "ตรวจทิศภาพ" ในเว็บวัดให้): 1 = ของที่มุมมากกว่าอยู่ซ้ายของภาพ, -1 = อยู่ขวา, 0 = ยังไม่ได้ตรวจ |
| `cam.res` | i | 1 | 0 … 5 |  | 0 = 320×240, 1 = 640×480, 2 = 800×600, 3 = 1024×768, 4 = 1280×720, 5 = 1600×1200 |
| `cam.q` | i | 12 | 4 … 63 |  | คุณภาพ JPEG (เลขน้อย = ชัด ไฟล์ใหญ่) |
| `cam.flush` | i | 2 | 0 … 5 |  | จำนวนเฟรมที่ทิ้งก่อนถ่ายจริง (กันภาพค้าง) |
| `cam.aec` | i | 300 | 0 … 1200 |  | ค่า exposure ตอนล็อก |
| `cam.agc` | i | 0 | 0 … 30 |  | ค่า gain ตอนล็อก |
| `cam.off` | f | 0 | -30 … 30 | deg | มุมเยื้องของกล้องเทียบแกนเซนเซอร์ (boresight) |
| `cam.hfov` | f | 62 | 10 … 140 | deg | มุมรับภาพแนวนอนของกล้อง (ปุ่ม "ตรวจทิศภาพ" วัดให้) |

## การสื่อสาร (com)

| key | ชนิด | ค่าเริ่มต้น | ช่วง | หน่วย | ความหมาย |
|---|---|---|---|---|---|
| `com.hz` | i | 20 | 0 … 100 | Hz | อัตราส่ง telemetry |
| `com.hk` | i | 2 | 0 … 60 | s | ส่งสุขภาพระบบ (J hk: อุณหภูมิชิป, หน่วยความจำ, แรงดันแบต, loop นานสุด) ทุกกี่วินาที (0 = ปิด) |
| `com.rx` | i | -1 | -1 … 48 |  | ขา RX ของช่องสื่อสารที่สอง (UART ต่อวิทยุ HC-12/LoRa หรือบอร์ดสะพาน) -1 = ไม่ใช้ |
| `com.tx` | i | -1 | -1 … 48 |  | ขา TX ของช่องสื่อสารที่สอง (-1 = ปิดช่องที่สอง) ช่องนี้ได้สำเนาทุกบรรทัด และรับคำสั่งได้เหมือน USB |
| `com.baud` | i | 115200 | 1200 … 2000000 | baud | ความเร็วช่องที่สอง ต้องตรงกับวิทยุ/บอร์ดสะพาน (HC-12 ปกติ 9600) |
| `com.lhz` | i | 2 | 0 … 50 | Hz | อัตราส่ง telemetry ทางช่องที่สอง (วิทยุช้าใช้ 1–2 Hz) |
| `com.limg` | i | 1 | 0 … 1 |  | 1 = ส่งภาพทางช่องที่สองด้วย (ภาพจะช้าตามวิทยุ: 320×240 ที่ 9600 baud ≈ 10 s ใช้ cam.res 0) 0 = ภาพออกทาง USB อย่างเดียว |

## ฮาร์ดแวร์อื่น (hw)

| key | ชนิด | ค่าเริ่มต้น | ช่วง | หน่วย | ความหมาย |
|---|---|---|---|---|---|
| `hw.sda` | i | 8 | -1 … 48 |  | ขา SDA สำหรับสแกน I2C (HWID I2C) ใส่ -1 = ไม่สแกน |
| `hw.scl` | i | 9 | -1 … 48 |  | ขา SCL สำหรับสแกน I2C (HWID I2C) |
| `hw.btn` | i | 0 | -1 … 48 |  | ขาปุ่มกดเริ่ม/หยุดภารกิจ 1 (ปุ่มต่อลง GND) 0 = ปุ่ม BOOT บนบอร์ด, -1 = ไม่ใช้ (ถ้ากล้องใช้ขานี้จะปิดปุ่มให้เอง) |
| `hw.vbat` | i | -1 | -1 … 48 |  | ขา ADC วัดแรงดันแบตผ่านวงจรแบ่งแรงดัน (-1 = ไม่มี) ค่าออกใน J hk |
| `hw.vdiv` | f | 2 | 1 … 20 |  | อัตราส่วนวงจรแบ่งแรงดันแบต = แรงดันแบต / แรงดันที่ขา (เช่น 100k + 100k = 2) |
