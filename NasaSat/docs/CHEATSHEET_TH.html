NasaSat cheat sheet (พิมพ์ 1 หน้า พกติดตัว)

ต่อบอร์ด: ปิด Serial Monitor → Chrome เปิด tool/NasaSatLab.html → บอร์ดจริง → เชื่อมต่อ (บอร์ดรีเซ็ตแล้วเว็บต่อใหม่เอง 30 s) · อัปโหลดใหม่ต้องกด "ตัดการเชื่อมต่อ" ก่อน
ฉุกเฉิน: STOP = Space / Esc · REBOOT · ไม่รอดจริง: firmware/Fallback/Fallback.ino

ตั้งค่ากับชุดใหม่

ทำคำสั่ง
ดูบอร์ดHWID
หาขา LDRPINFIND ON บังมือ → SET sen.pin0 N / SET sen.pin1 N → PINFIND OFF
บังมือแล้ว mV เพิ่มSET sen.topo 1
ขา ULN2003SET act.in1 N … act.in4 → MOVE 10 ต้องหมุน
ทิศMOVE 10 แล้ว θ ต้องลด ไม่งั้น SET act.dir -1
กล้องSET cam.model 1/2/3/4 (4 = ESP32-CAM) → M2 INIT → หน้า ภารกิจ 2 → เตรียมกล้อง: พลิกภาพ → ตรวจทิศภาพ
เก็บSAVE ทั้งหมด หรือ SAVE key1 key2 เฉพาะบางค่า (+ Export โปรไฟล์)

คาลิเบรต

1 หันเข้าหลอด ZERO · 2 BACKLASH → act.bl (แล้ว SPR → act.spr ถ้าหมุน 360° ได้) · 3 ปิดหลอด → AMB · 4 เปิดหลอด → Sweep −60..60 ทีละ 5 · 5 γ สองระดับ: วัดระดับ 1 → กระดาษบังหน้าหลอด (≥ 2 เท่า) → วัดระดับ 2 · 6 Fit (MAE < 0.3°, γ ขวา/ซ้าย "ใช้แล้ว") · 7 ตรวจ · 8 ส่ง + SAVE · 9 หันตรงหลอดด้วยของอ้างอิง → ตั้งศูนย์ (CAL TH0 0 บันทึกเอง)
ไฟห้องเปลี่ยน = ตรวจศูนย์ด้วยท่อเล็ง → CAL TH0 ใหม่ (ห้ามวัด AMB ใหม่อย่างเดียว)

ภารกิจ

คำสั่งดูอะไร
ภารกิจ 1M1 START มุม · M1 STOPE M1 HOLD t= it= err= · ตาราง "ผ่าน"
ทดสอบตอบสนองSTEP 10 (ตอน HOLD)step_result
boresight (หลังตั้งศูนย์)ปุ่ม "ล็อกหลอดแล้ววัด boresight" → ใช้ค่านี้ + SAVEcam.off
ภารกิจ 2M2 GO SUN offset (แนะนำ) · M2 GO มุม · M2 SNAPภาพ + metadata · snap_fail = ไม่ถ่ายพร้อมเหตุผล
ไม่รู้มุมเป้าสแกนรอบตัว → คลิกภาพ → คลิกเป้า → GO / เทียบดวงอาทิตย์เป้ากลางภาพ
แสงกล้องM2 LOCK / M2 UNLOCKlocked ใน metadata
ไม่ต่อคอมSET m1.auto 5 + SAVE m1.auto · ปุ่ม BOOT เริ่ม/หยุด · STOP ยกเลิกตอนรอE AUTO ..., E BTN ...
วิทยุ serialSET com.baud 9600 · com.rx · com.tx → SAVEE LINK ON, J hk link.drop

แก้ปัญหาเร็ว

อาการทำ
เงียบปิด Serial Monitor, เปลี่ยนสาย, กด RESET
E BOOT BROWNOUTไฟไม่พอ: แยกไฟมอเตอร์ / hub มีไฟ
adc_saturatedถอยหลอด / กระดาษบางทั้งคู่ → คาลิเบรตใหม่
ไม่หมุนขา act.in ผิด / ไฟ 5 V มอเตอร์
วิ่งหนีแสงSET act.dir -1
ภาพไม่ขึ้นcam.model อื่น → M2 INIT (not for this chip = เลือก preset ผิดชิป)
คลิกเป้าแล้วพลาดไปอีกฝั่ง"ตรวจทิศภาพ" ใหม่
ERR BUSY Xงาน X ค้าง: รอ หรือ STOP
ERR RANGEค่าเกินช่วง (ดู min..max ในข้อความ)
ERR PINขานี้ใช้ไม่ได้ (flash/PSRAM/USB หรือไม่ใช่ขา ADC) อ่านเหตุผลท้ายบรรทัด

รหัส ERR: CMD ไม่รู้จักคำสั่ง · ARG อาร์กิวเมนต์ผิด · KEY ไม่มีค่านี้ · VAL ไม่ใช่ตัวเลข · RANGE นอกช่วง · BUSY มีงานอื่น · STATE สถานะไม่ถูก · CAM กล้องไม่พร้อม · LONG บรรทัดยาวเกิน
