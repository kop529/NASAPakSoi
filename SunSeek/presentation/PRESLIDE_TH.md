## ส่วน A — Workshop T01 / T02

### สไลด์ 1 · ปก
- นาซ่าหน้าปากซอย · SunSeek Reaction Wheel ADCS
- Workshop T01 + T02 ผ่านทั้งคู่ (10 คะแนน)
- 🖼 รูปดาวเทียมที่ประกอบเสร็จ

### สไลด์ 2 · ระบบของเรา
- บอร์ด SunSeek v1.3 (ESP32-S3) + TB6612 ขับมอเตอร์ล้อปฏิกิริยา
- Sun sensor (LDR 2 ตัววางเป็นรูปตัว V)
- คุมผ่าน BLE ด้วย MUT Ground Station v1.9 และ USB ด้วยเครื่องมือของทีม
- 🖼 แผนภาพ: GS ⇄ BLE ⇄ ESP32 → TB6612 → มอเตอร์ → ล้อ → ตัวยาน
- 🎤 "ตัวยานหมุนได้เพราะล้อหมุนสวนทาง โมเมนตัมเชิงมุมของทั้งระบบคงที่"

### สไลด์ 3 · ผล T01: ลักษณะของล้อ [บอร์ดจริง]
| หัวข้อ | ค่า |
|---|---|
| ทิศ (มองจากบน ประกอบแล้ว) | + = ตามเข็ม, − = ทวนเข็ม |
| Min Start / Min Stable | ±10 % / ±5 % |
| ช่วงเชิงเส้น | 20–80 % |
| สั่น / สมมาตร | ไม่สั่น / สมมาตร + − |
| STOP | coast ~6 วินาที จาก 30 % |
- 🖼 วิดีโอล้อไหลจนหยุดหลัง STOP (`day1\*.mp4`) และภาพออสซิลโลสโคป
- 🎤 "วัดก่อนออกแบบตัวควบคุม ค่า Min Start / Min Stable เอาไปใช้ใน F4"

### สไลด์ 4 · ผล T02: BLE + Momentum [บอร์ดจริง]
- PING → PONG, STATUS ผ่าน BLE
- Reaction mode: ตัวยานหมุนสวนล้อ
- Momentum mode: ล้อหมุนค้างที่ bias 40 % ตัวยานนิ่ง
- Assist `RW_CMD,+20,+80,300` → `EVT,RW_MANEUVER_COMPLETE,60`
- 🖼 แคปหน้าจอ GS: PONG, STATUS, EVT (ยังต้องแคป)

### สไลด์ 5 · ปัญหา 1: ล้อไม่หมุน (ต้องสั่งถึง 50 %)
- **สมมติฐาน:** น็อตหนักเกิน → โค้ดผิด → ไฟไม่พอ
- **พิสูจน์:** ส่งคำสั่งชุดเดียวกับสคริปต์ทีละคำสั่ง ผลเหมือนกัน แปลว่าโค้ดไม่ผิด
- **สาเหตุจริง:** ไฟเลี้ยงมอเตอร์ไม่พอ หลังแก้ Min Start ลดจาก ~50 % เหลือ 10 %
- 🎤 "เปลี่ยนตัวแปรทีละตัว และตรวจไฟเลี้ยงก่อนโทษโค้ด"

### สไลด์ 6 · ปัญหา 2: ทิศสลับ
- ใบ T01 จดว่า + = ทวนเข็ม แต่ตอนประกอบแล้ว + = ตามเข็ม เพราะตอนวัดมองคนละด้าน
- **แก้:** กำหนด convention ว่า "มองจากด้านบน ตอนประกอบแล้ว"
- 🎤 "ถ้าทิศผิด ระบบควบคุมจะหมุนหนีเป้า"

### สไลด์ 7 · ปัญหา 3: ±10 % ไม่ขยับ, ตัวยานย้อนหลัง STOP, Momentum เงียบ
- **แรงบิดเกิดตอนความเร็วล้อเปลี่ยน (τ = −dH/dt):**
  - ถ้าเปลี่ยนทีละ ±10 % แรงบิดน้อยกว่าแรงเสียดทานของแท่น จึงต้องใช้ Assist เตะแรง ๆ สั้น ๆ
- **STOP เป็นแบบ coast:**
  - ล้อค่อย ๆ ช้าลง แรงเสียดทานในมอเตอร์คืนโมเมนตัมให้ตัวยาน ตัวยานจึงหมุนย้อนนิดหนึ่ง
- **สั่ง `ADCS_STRATEGY,MOMENTUM` แล้วไม่มีอะไรเกิดขึ้น:**
  - คำสั่งนี้แค่เปลี่ยนโหมด ต้องสั่ง `RW_BIAS` ต่อ จะเห็นล้อหมุนค้างโดยตัวยานนิ่ง
- 🖼 กราฟ: ความเร็วล้อเทียบกับแรงบิดที่ตัวยานได้รับ

### สไลด์ 8 · ปัญหา 4: RW,100 → RW,−100 แล้ววงเหล็กถ่วงหลุด [บอร์ดจริง]
- ตัวยานหมุนสวนทันที ทั้งที่ล้อยังไม่กลับทิศ ถูกต้องตามฟิสิกส์ เพราะแรงบิดกลับด้านทันทีที่มอเตอร์เริ่มเบรก
- กระโดด +100 → −100 มอเตอร์เจอแรงดันเกือบ 2 เท่า กระแสพุ่ง วงถ่วงจึงกระเด็น และเสี่ยงไฟตกจนบอร์ดรีเซ็ต
- ขันน็อตยึดจานล้อให้ตรง ไม่ส่าย ทำให้ล้อเร็วขึ้นราว 1 → 3 รอบ/วินาที แปลว่าแท่นเปลี่ยนนิดเดียวระบบก็เปลี่ยน
- **แก้:** เพิ่มตัวจำกัดอัตราเปลี่ยนคำสั่ง (`rw.slew`) และจูนค่าในสนามด้วย `TEAM_SET`

### สไลด์ 9 · ปัญหา 5: Ground Station หาบอร์ดไม่เจอ
- **สาเหตุ:**
  - บอร์ดไม่มีไฟ
  - ค้างสถานะ `BLE,CONNECTED` ของการเชื่อมเก่า
  - BLE รับได้ทีละ 1 การเชื่อม
- **แก้:** RESET บอร์ด → เปิด GS ใหม่ → สแกนใหม่ → เช็ก MAC `...FF:99` ก่อนกด connect (มีบอร์ดทีมอื่นอยู่ใกล้ ๆ)
- 🎤 "BLE หลุดแล้วล้อไม่หยุดเอง เราจึงมีทางสั่ง STOP สำรองทาง USB"

### สไลด์ 10 · ปัญหา 6: เครื่องมือของทีม (`t01.ps1`)
- สคริปต์พาวัด T01 ทีละขั้น และบันทึกผลเป็นไฟล์เองโดยอัตโนมัติ
- **บั๊กที่แก้:**
  - `$r` กับ `$R` เป็นตัวแปรเดียวกันใน PowerShell
  - ไฟล์ต้องเป็น UTF-8 แบบมี BOM
  - จด Min Stable ทั้งที่ล้อไม่เคยหมุน
- **ความปลอดภัย:** สั่ง STOP เสมอ แม้กด Ctrl+C (บล็อก `finally`)

## ส่วน B — เฟิร์มแวร์ของทีม: แก้อะไร และทำไมดีกว่า

### สไลด์ 11 · หลักการแก้โค้ดกรรมการ
1. รูปแบบ TM / ACK เหมือนเดิม Ground Station ของกรรมการใช้ได้ คำสั่งใหม่ขึ้นต้น `TEAM_`
2. ค่าเริ่มต้นเท่ากับของกรรมการ flash ว่างก็ทำงานเหมือนเดิม ถอยกลับได้ทันที
3. ทุกจุดที่แก้มีป้าย `TEAM NasaPakSoi`
4. มี 2 ชุด: ชุด workshop (เกือบเหมือนต้นฉบับ ใช้ให้ครูตรวจ) และชุด team (ใช้แข่ง)

### สไลด์ 12 · ตารางเทียบ: กรรมการ vs ของเรา
| # | ของกรรมการ v2.1 | ของเรา | ผล |

### สไลด์ 13 · ทำไมมุมของกรรมการคลาด และโมเดลของเรา
- **ปัญหาของ 90 × NDV:**
  - LDR ไม่เชิงเส้น (R ∝ แสง^−γ)
  - วงจรแบ่งแรงดันเพิ่มความไม่เชิงเส้นอีกชั้น
  - มีแสงรอบข้างปน
  - ผลเปลี่ยนตามความสว่างและระยะหลอด
- **โมเดลของเรา:**
  - V → G = V/(Vcc−V)
  - ^(1/γ) − แสงรอบข้าง
  - ปรับ gain ซ้าย/ขวาให้เท่ากัน
  - D = (L−R)/(L+R)
  - θ = atan(D / tan α) + th0 + LUT
- 🖼 กราฟมุมจริงเทียบกับมุมที่คำนวณ: เส้นของเรา vs เส้น 90 × NDV
- 🎤 "ใช้สูตรกรรมการเป็นค่าเริ่มต้น จะเปลี่ยนไปใช้โมเดลเราหลัง calibrate กับแท่นจริงเท่านั้น"

### สไลด์ 14 · F4: ทำไม PD ของกรรมการค้างก่อนเป้า และวิธีแก้ [จำลอง]
- **สาเหตุ:** PWM กำหนด "ความเร็ว" ล้อ ไม่ได้กำหนด "แรงบิด"
  - แรงเสียดทานที่แท่นดูดโมเมนตัมของตัวยานออกไป แต่ล้อยังหมุนค้างอยู่
  - ต้องมี Kp·e ≠ 0 คอยค้ำความเร็วล้อไว้ ระบบจึงหยุดห่างเป้า
- **วิธีแก้:**
  - เทอม I (`adcs.ki`) สะสม PWM ที่ต้องใช้ค้ำความเร็วล้อแทน Kp·e
  - ในช่วง deadband ให้คงค่า I ไว้ ไม่ปล่อยให้ล้อไหลจนหยุด
- **ผลจำลอง:** lamp +30°, เป้า 0°, 30 วินาที

| แท่น | PD กรรมการ | + ki 1, db 0.5 | + ki 1, db 0.5, kp 4, kd 1 |
|---|---|---|---|
| แรงเสียดทานหนืด | ค้าง 4.8° | 0.5° | 0.5° |
| + แรงเสียดทานสถิต | ค้าง 11.4° | 0.6° | **0.14°** |
| ลื่นมาก (ไม่มีแรงเสียดทาน) | ค้าง 1.7° | 1.8° (เลยเป้า 9.5°) | 0.4° (เลยเป้า 6.3°) |
- 🎤 "ค่าที่ได้จากการจำลองเป็นจุดเริ่ม ค่าจริงจะจูนบนแท่นสนามผ่าน `TEAM_SET` โดยไม่ต้องอัปใหม่"

### สไลด์ 15 · ความปลอดภัยที่ใส่ไว้
- STOP ตัดไฟมอเตอร์ทันทีเสมอ แม้เปิดตัวจำกัดอัตรา slew อยู่
- ค่าที่อยู่นอกช่วงถูกปฏิเสธ ทั้งตอนสั่งและตอนโหลดจาก flash
- ห้ามเปลี่ยนค่า sign ระหว่าง AUTO
- integrator ถูกจำกัดไม่ให้เกิน adcs.max (anti-windup)
- ห้ามสั่ง ±100 สลับทิศ วงถ่วงต้องยึดแน่น

### สไลด์ 16 · ข้อจำกัดและงานต่อไป
- ทดสอบบนบอร์ดจริงแล้ว: T01, T02 และ RW_CMD
- ยังเป็นผลจำลอง: โมเดลมุม, เทอม I, slew
  - ตรวจในโปรแกรมจำลองทั้งระบบแล้ว (ตอนนี้ 61 รายการผ่าน)
  - ต้องยืนยันบนบอร์ดจริง
- **งานต่อไป:**
  - F5 ล็อกเป้าแบบ hysteresis
  - F6 หา gyro bias อัตโนมัติ
  - F7 ค้นหาดวงอาทิตย์
  - ภารกิจกล้อง (หลังอบรม 6 ต.ค.)

### สไลด์ 17 · สิ่งที่ทีมได้เรียนรู้
1. ฟิสิกส์: แรงบิดมาจากการเปลี่ยนความเร็วล้อ และโมเมนตัมเชิงมุมอนุรักษ์
2. วัดแอกชูเอเตอร์ก่อน แล้วค่อยออกแบบตัวควบคุม
3. ตั้งสมมติฐาน แล้วทดสอบทีละตัวแปร
4. ระบุทิศและมุมมองให้ชัดตั้งแต่แรก
5. แก้ระบบเดิมให้น้อยที่สุด และไม่ทำลายส่วนที่ระบบอื่นใช้อยู่
6. เตรียมขั้นตอนกู้คืนเมื่อการเชื่อมต่อหลุด และมีทางหยุดฉุกเฉินสำรอง
