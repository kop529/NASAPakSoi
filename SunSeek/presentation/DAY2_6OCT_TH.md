## 2. ต่อ IMU (GY-89) [บอร์ดจริง]
- **ปัญหา:** วันแรก IMU = NOT_DETECTED (ยังไม่ได้ต่อสาย)
- **กับดัก:** ตารางในสมุด T03 เขียน SCL = GPIO08, SDA = GPIO09 แต่เฟิร์มแวร์และหน้า Appendix ของสมุดเองเขียนกลับกัน
- **แก้:** ต่อตามเฟิร์มแวร์ **SDA → GPIO08, SCL → GPIO09** → ACCEL/MAG/GYRO READY, BARO DETECTED
- **บทเรียน:** เอกสารขัดกันเอง ให้เชื่อโค้ดที่รันจริง

## 3. แท่นวัดมุมของผู้จัด = เครื่องคาลิเบรตสำเร็จรูป [บอร์ดจริง]
- แผ่นขาวมีขีด −85…+85 ทุก 5° + จานไม้หมุน + **ขาอะคริลิกใส = ที่ยึดไฟ**
- ตอนแรกเราเข้าใจผิดว่าขาใสคือเข็มชี้ → พอรู้ก็ใช้คาลิเบรตได้: **ยานนิ่ง เลื่อนไฟไปทีละขีด**
- 🖼 รูปแท่น (ถ่ายไว้ 6 ต.ค.)

## 4. คาลิเบรต sun sensor [บอร์ดจริง]
- Sweep 25 จุด (ขีด −60…+55 และ 80) ผ่านเว็บ NasaSat Lab โหมด SunSeek
- **ปัญหา:** ครั้งแรก Fit ไม่ผ่าน (MAE 1.65°, error สูงสุด 19°)
  - **สาเหตุ:** จุดขีด 80 ไฟอยู่เกือบข้างยาน LDR มืดทั้ง 2 ฝั่ง ค่าซ้ำกับมุมอื่น
  - **แก้:** Export CSV → ตัดจุดนั้น → Import → **MAE 0.07°, error สูงสุด 0.26°, ใช้ได้ −60…+50°**
- **ลอง γ สองระดับแสง:** แย่ลง (γ 0.30 ผิดธรรมชาติ, สูงสุด 2.2°) → ไม่ใช้ (บังไฟด้วยกระดาษไม่สม่ำเสมอ / ไฟมือถือปรับเอง)
- **พบว่า SunSeek มี LDR 4 ตัว (ฝั่งละ 2)** → สูตรฟิสิกส์อย่างเดียวคลาด ~10° แต่ตาราง LUT แก้เหลือ < 0.5°
- **ตรวจหลังคาลิเบรต (T03 Exp 2):** ไฟที่ −40/−20/0/+20/+40 → อ่านได้ −39.98/−19.47/+0.96/+20.22/+39.87°
- **เทียบผู้จัด:** NDV เปลี่ยนแค่ ±0.08 และไม่สมมาตร → สูตร 90×NDV ได้แค่ ±5–7° ที่มุมจริง ±40°
- 🎤 "สูตรของผู้จัดบอกว่าไฟอยู่ที่ 7° ทั้งที่จริงอยู่ที่ 40° ของเราบอก 39.9°"

## 5. ทิศของ gyro และทิศการคุม [บอร์ดจริง]
- **gyro:** หมุนยาน 45° ด้วยมือ gyro นับได้ 44.6° → สเกลถูก แต่ **มุมแสงกับ gyro สวนทางกัน** (corr −0.78) → ตั้ง `imu.rsign -1`
  - ตรวจซ้ำหลังตั้ง (ถือไฟนิ่ง หมุนยาน): ไปทางเดียวกัน corr **+0.64** ✅
- **gyro zero:** วัดตอนยานนิ่ง 3 วิ ได้ bias **1.237 °/s** → หลังตั้งอ่านได้ ±0.1 °/s
- **ทิศการคุม (`adcs.sign`):** ล้อ + ตอนเร่ง → มุม + / ตอนไหลหยุด → มุม − ทั้งทาง USB และ BLE → **+1 ถูก**
- **ปัญหาระหว่างทาง:**
  - ครั้งแรกหมุนแต่ไฟ ยานไม่หมุน → gyro = 0 (ถูกต้อง!) → บทเรียน: ต้องบอกให้ชัดว่า "หมุนอะไร"
  - kick 0.5 วิ สั้นเกิน ล้อยังเร่งไม่ทัน แรงบิดน้อยกว่าแรงเสียดทาน → ใช้ 3 วิ

## 6. สาย USB คือเบรกของยาน [บอร์ดจริง]
- เสียบ USB: สั่ง RW,40 ค้าง 4 วิ ยานขยับ 0.1°
- ถอด USB ใช้ BLE + แบต: RW,40 ยาน**หมุนหลายรอบ** (คลิป `proove.mp4`)
- **บทเรียน:** จูนทุกอย่างบน BLE + แบตเท่านั้น ค่าที่จูนตอนเสียบสายใช้แข่งไม่ได้
- อีกเรื่อง: บอร์ดดับทันทีเมื่อถอด USB ถ้ายังไม่เปิดสวิตช์แบต (GS หาไม่เจอ)
- แท่นจริง: **ต้อง > 25% ถึงเริ่มขยับ แต่พอขยับแล้วลื่นมาก** (stick-slip)

## 7. AUTO ครั้งแรกบนแท่นจริง [log GS]
- **รอบ 1** (kp 4, max 80): ล้อเต็มแรง ยานพุ่งเลยไฟไปฝั่งตรงข้าม แล้วค่อยกลับมาเข้าไฟ ค้างที่ +1.x°
- **รอบ 2** (max 40, kp 2, kd 2, ghold 1): ครั้งหนึ่งล้อไม่หมุนเลย (ไฟ/สาย) แก้แล้ว log `newww.csv`:
  - เริ่มที่ −18° แต่ล้อถูกสั่ง **−40 (ผิดทาง)** → ยานหมุน ~2 รอบ (gyro ตันที่ ±286 °/s)
  - จากนั้นกลับมาเข้าเป้า **0 ±1° ค้างนิ่ง** ล้อค้าง +12…15% (เทอม I ต้านแรงลากของล้อ)
  - ช่วงหลังทิศถูก → สาเหตุที่ช่วงแรกผิดทางยังหาอยู่ (สงสัยมุมประมาณ EST ไม่ตรงกับมุมแสงตอนเริ่ม)
- **บทเรียน:** "ถึงเป้าได้" ≠ "ถึงเป้าดี" ต้องจำกัดแรง (max), เพิ่มการเบรก (kd) และมี log ทุกครั้ง

## 8. กราฟ GS แกว่งซิกแซก ±150 °/s ไม่ใช่การสั่น [log GS]
- ใน log คอลัมน์ gyro_z สลับ + / − ทุกแถว
- **สาเหตุ:** บอร์ดส่งคีย์ `GYRO_Z` จาก 2 บรรทัด: บรรทัด GYRO = ค่าดิบ, บรรทัด ADCS = body rate (ซึ่งเราตั้งให้กลับทิศ) GS เอามาวาดรวมกัน
- **แก้:** ให้ทุกบรรทัดส่งค่าดิบใต้คีย์ `GYRO_Z` (โค้ดคุมยังใช้ body rate ที่ถูกทิศ)
- **บทเรียน:** ก่อนสรุปจากกราฟ ดูข้อมูลดิบก่อน (เราเคยสรุปผิดว่ายานสั่น)

## 10. F8: หันไปเป้าที่เซนเซอร์แสงมองไม่เห็น + เปลี่ยนเป้าระหว่าง AUTO [จำลอง]
- **ปัญหา:** เซนเซอร์แสงเห็นแค่ ±55° แต่เป้ากล้องอาจอยู่ไกลกว่านั้น พอหลุดไฟ มุมที่อ่านได้เป็นขยะ

## 12. บทเรียนของวัน
1. **ฟิสิกส์:** ล้อยืมโมเมนตัมตอนเร่ง คืนตอนไหลหยุด → `RW_STOP` ไม่ได้แปลว่าหยุดยาน
2. **การทดลอง:** บอกให้ชัดว่าขยับอะไร (ยาน / ไฟ / จาน), จับอะไรไว้, ห้ามแตะอะไร
3. **สภาพทดสอบ = สภาพแข่ง:** สาย USB ทำให้ผลผิดทั้งหมด
4. **ข้อมูลดิบก่อนสรุป:** กราฟซิกแซกไม่ใช่การสั่น, ยานไม่หมุนไม่ใช่ IMU ไม่ได้ติด
5. **เอกสารผิดได้:** ตารางสาย IMU, LDR "Left" ซ้ำ, โค้ดกล้องที่ผู้จัดบอกเองว่ายังไม่เคยทดสอบบนฮาร์ดแวร์
6. **ระบบใหญ่มีหลายชั้น:** คำสั่ง (BLE) กับภาพ (Wi-Fi) เป็นคนละเส้นทาง ต้องเช็คทีละชั้น
